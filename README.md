# curso-backend-node

Estrutura inicial do curso com frontend estatico e backend Node.js (Hello World).

## Estrutura

```text
curso-backend-node/
├── backend/
│   ├── package.json
│   └── server.js
├── css/
├── js/
└── index.html
```

## Rodar o Hello World

1. Entre na pasta do backend:

```bash
cd backend
```

2. Rode o servidor em desenvolvimento:

```bash
npm run dev
```

3. Abra no navegador:

```text
http://localhost:3000
```

Resposta esperada:

```json
{"message":"Hello World do Node.js!"}
```
